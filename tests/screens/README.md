# Проверка на снимках

Каждый случай — снимок страницы `имя.png` и рядом `имя.expect`: что программа должна
(и не должна) найти на снимке. Проверку запускает CI после каждой сборки
(отчёт — на странице сборки, раздел Summary), а локально:

    manga-local.exe --selftest tests\screens --out отчёт.md

Сейчас здесь три нарисованные страницы (корейская, японская, английская) (`tools/screens/make_pages.py`). Настоящие
страницы добавляются так: **Ctrl+F9** на странице с мангой — программа сохранит экран
и черновик `.expect` в `%LOCALAPPDATA%\MangaLocal\cases`. Черновик правится руками и
кладётся сюда вместе со снимком.

Правила `.expect` (одно в строке, `ключ<TAB>значение`, `#` — комментарий):

| Правило | Значит |
|---|---|
| `lang ko` / `lang ja` / `lang zh` / `lang en` | язык текста |
| `bubble текст` | какой-то пузырь (F8) содержит этот текст (ошибки OCR допускаются) |
| `bubbles N` | F8 находит ровно N пузырей (проверка сборки строк в пузыри) |
| `absent текст` | этого нигде нет |
| `label текст` | среди отдельных строк F8 есть такая |
| `speech текст`, `speaker Имя`, `max_speech N` | старый режим субтитров |
