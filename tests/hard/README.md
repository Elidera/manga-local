# Трудные случаи

28 нарисованных страниц из набора `comic_ocr_dataset` (сделаны специально для
проверок, не взяты из настоящих комиксов): вертикальный японский, мелкий текст,
звуки, тёмные пузыри, наклонный текст, переписка в телефоне, пустые страницы.
Правила `.expect` — как в `tests/screens`.

CI проверяет их отдельно и **не останавливает сборку**, если что-то не прошло:
это мерило, сколько трудных случаев программа уже умеет.

На CI установлено распознавание корейского и японского (английское есть в
Windows сразу); китайские страницы там помечаются «не установлен», пока
китайское распознавание не добавлено в CI.
