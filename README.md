# Manga Local

Локальный нейросетевой переводчик манги, манхвы и маньхуа на русский для Windows 10/11.
Всё работает на вашем компьютере и бесплатно: распознавание текста — встроенное в Windows,
перевод — нейросеть Hy-MT2 через llama.cpp. Интернет нужен только один раз, чтобы скачать модель.

Программа сделана на основе [Wuxia Local](https://github.com/Elidera/wuxia-local) (коммит d2ee424), но дальше развивается отдельно: изменения здесь не затрагивают Wuxia Local.

## Как пользоваться

1. В панели (F10) → «Настройки → Где читаете» выберите язык: корейский (манхва), японский (манга) или китайский.
2. Откройте главу в браузере.
3. Нажмите **F8** — программа найдёт пузыри и впишет перевод прямо в них. Повторное нажатие убирает перевод.
   Прокрутили страницу — перевод исчезнет сам.
4. Плохой перевод — **Ctrl+F11**: страница переведётся заново.

| Клавиша | Что делает |
|---|---|
| F8 | Перевести страницу / убрать перевод |
| F9 | Оригинал / перевод |
| F10 | Панель |
| Ctrl+F8 | Стоп-кадр: нажмите на текст — перевод |
| Ctrl+F11 | Плохой перевод: перевести страницу заново |
| Ctrl+F9 | Сохранить экран для проверки (разработчику) |

## Установка

1. Скачайте `MangaLocal-Setup-x.y.z-x64.exe` со страницы сборок (Actions → build → Artifacts) и запустите. Права администратора не нужны.
2. Оставьте галочку «Установить модули распознавания текста Windows» — корейский, японский, китайский и английский.
3. При первом запуске программа один раз скачает модель (~1,1 ГБ).

### Где лежат данные

`%LOCALAPPDATA%\MangaLocal`: `config.toml`, `models\`, `cache.tsv`, `corrections.tsv`, `glossary\user.tsv`, `logs\`.
Портативный режим: если рядом с exe лежит `portable.txt`, всё хранится в папке `data` рядом с программой.

Manga Local и Wuxia Local можно ставить рядом: у них разные папки программы и данных.

## Устройство

```
crates/core   ядро (скопировано из Wuxia Local, тесты на любой ОС):
              lang.rs, text.rs   корейский, японский, китайский: определение языка, очистка строк OCR
              layout.rs          строки → пузыри, порядок чтения, подбор размера шрифта под пузырь
              prompt.rs          промпты Hy-MT и Qwen для манги, пакет «все пузыри страницы»
              glossary.rs, cache.rs, image.rs  словари, кэш переводов, цвет бумаги вокруг текста
crates/app    manga-local.exe (Windows): захват экрана, Windows OCR, llama-server, оверлей, трей, панель
              interface.rs       F8: OCR страницы → пузыри → пакетный перевод → перевод в пузыре
tests/screens нарисованные страницы с пузырями для проверки в CI (tools/screens/make_pages.py)
crates/bench  проверка качества перевода на наборе строк (.github/workflows/quality.yml)
```

## Сборка (для разработчиков)

```
cargo test -p wuxia-core              # на любой ОС
cargo build -p manga-local --release  # Windows 10/11 x64, MSVC
```

Установщик и portable-архив собирает GitHub Actions (`.github/workflows/release.yml`) на каждый push в main. Хранятся 5 последних сборок. Тег `v*` публикует релиз.
