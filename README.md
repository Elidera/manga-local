# Manga Local

Локальный нейросетевой переводчик манги, манхвы и маньхуа на русский для Windows 10/11.
Всё работает на вашем компьютере и бесплатно: распознавание текста — встроенное в Windows,
перевод — нейросеть Hy-MT2 через llama.cpp. Интернет нужен только один раз, чтобы скачать модель.

Программа сделана на основе [Wuxia Local](https://github.com/Elidera/wuxia-local) (коммит d2ee424), но дальше развивается отдельно: изменения здесь не затрагивают Wuxia Local.

## Как пользоваться

1. В панели (F10) → «Настройки → Где читаете» выберите язык: корейский (манхва), японский (манга), китайский (маньхуа) или английский (переводы манхвы и комиксы; текст заглавными буквами программа переводит как обычный).
2. Откройте главу в браузере.
3. Нажмите **F8** — программа найдёт пузыри и впишет перевод прямо в них. Дальше просто листайте: пока страница едет, перевод спрятан, а когда остановится — новые пузыри переводятся сами. Повторное F8 выключает перевод.
4. Скачанная глава: кнопка **«Перевести файлы главы»** в панели — выберите архив ZIP/CBZ или любую картинку из папки главы. Рядом появится «<глава> (перевод)» с переведёнными картинками.
5. Плохой перевод — **Ctrl+F11**: страница переведётся заново.

| Клавиша | Что делает |
|---|---|
| F8 | Включить перевод страницы (дальше сам при прокрутке) / выключить |
| F9 | Оригинал / перевод |
| F10 | Панель |
| Ctrl+F8 | Стоп-кадр: нажмите на текст — перевод |
| Ctrl+F11 | Плохой перевод: перевести страницу заново |
| Ctrl+F9 | Сохранить экран для проверки (разработчику) |

## Состояние

| Этап | Что появится | |
|---|---|---|
| 0 — основа | Своё имя, установщик, трей, панель, сборка в GitHub Actions | готово |
| 1 — первая рабочая версия | Корейский и японский (горизонтальный) текст: F8 → пузыри → перевод внутри пузыря | готово |
| 2 — удобство | Автоперевод после прокрутки, словарь тайтла, оригинал под мышью, шрифты комиксов, стирание текста по форме букв | готово |
| 3 — режим файлов | Папка, ZIP или CBZ → переведённая глава рядом (длинные вебтуны режутся на куски для распознавания) | готово, проверяется |
| 4 — вертикальный японский | Второй движок распознавания | |

## Установка

1. Скачайте `MangaLocal-Setup-x.y.z-x64.exe` со страницы сборок (Actions → build → Artifacts) и запустите. Права администратора не нужны.
2. Оставьте галочку «Установить модули распознавания текста Windows» — корейский, японский, китайский и английский.
3. При первом запуске программа один раз скачает модель (~1,1 ГБ).

### Где лежат данные

`%LOCALAPPDATA%\MangaLocal`: `config.toml`, `models\`, `cache.tsv`, `corrections.tsv`, `glossary\user.tsv`, `logs\`.
Портативный режим: если рядом с exe лежит `portable.txt`, всё хранится в папке `data` рядом с программой.

Manga Local и Wuxia Local можно ставить рядом: у них разные папки программы и данных.

## Устройство

```
crates/core   ядро (скопировано из Wuxia Local, тесты на любой ОС):
              lang.rs, text.rs   корейский, японский, китайский, английский: определение языка, очистка строк OCR
              layout.rs          строки → пузыри, порядок чтения, подбор размера шрифта под пузырь
              prompt.rs          промпты Hy-MT и Qwen для манги, пакет «все пузыри страницы»
              glossary.rs, cache.rs, image.rs  словари, кэш переводов, цвет бумаги вокруг текста
crates/app    manga-local.exe (Windows): захват экрана, Windows OCR, llama-server, оверлей, трей, панель
              interface.rs       F8: OCR страницы → пузыри → пакетный перевод → перевод в пузыре
tests/screens нарисованные страницы с пузырями для проверки в CI (tools/screens/make_pages.py)
crates/bench  проверка качества перевода на наборе строк (.github/workflows/quality.yml)
```

## Сборка (для разработчиков)

```
cargo test -p manga-core              # на любой ОС
cargo build -p manga-local --release  # Windows 10/11 x64, MSVC
```

Установщик и portable-архив собирает GitHub Actions (`.github/workflows/release.yml`) на каждый push в main. Хранятся 5 последних сборок. Тег `v*` публикует релиз.

## Шрифты

В папке `fonts` — шрифты в стиле комиксов с русскими буквами: Balsamiq Sans
(Balsamiq Sans Project Authors) и Pangolin (Pangolin Project Authors), лицензия
SIL Open Font License 1.1 (тексты лицензий рядом со шрифтами). Программа
подключает их только для себя, в Windows они не устанавливаются.

## Нейросети распознавания

Скачиваются по желанию, в установщик не входят:

- **Распознавание-нейросеть** (настройка «Распознавание текста → Нейросеть»):
  модели PaddleOCR (© Baidu / PaddlePaddle Authors) в формате ONNX из проекта
  RapidOCR, лицензия Apache-2.0. Берутся с ModelScope (`RapidAI/RapidOCR`,
  версия 3.10.0): поиск текста PP-OCRv6 small, чтение — PP-OCRv6 small
  (китайский, японский), korean_PP-OCRv5 mobile, en_PP-OCRv5 mobile.
  Код движка — `crates/ocr`.
- **Вертикальный японский**: manga-ocr (kha-white/manga-ocr-base, Apache-2.0)
  в формате ONNX (`mayocream/manga-ocr-onnx`).
