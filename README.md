# Manga Local

Локальный нейросетевой переводчик манги, манхвы и маньхуа на русский для Windows 10/11.
Всё работает на вашем компьютере и бесплатно: распознавание текста — встроенное в Windows,
перевод — нейросеть Hy-MT2 через llama.cpp. Интернет нужен только один раз, чтобы скачать модель.

Программа сделана на основе [Wuxia Local](https://github.com/Elidera/wuxia-local) и использует его ядро.

## Состояние

Идёт **Этап 0**: программа собирается и ставится под своим именем. Пока внутри работает прежний
игровой переводчик Wuxia Local. Перевод пузырей появится на следующих этапах.

| Этап | Что появится |
|---|---|
| 0 — основа | Своё имя, установщик, трей, панель, сборка в GitHub Actions |
| 1 — первая рабочая версия | Корейский и японский (горизонтальный) текст в браузере: клавиша → пузыри → перевод поверх оригинала |
| 2 — удобство | Автоперевод после прокрутки, стоп-кадр, словарь тайтла, «плохой перевод» |
| 3 — режим файлов | Папка или CBZ → переведённые картинки |
| 4 — вертикальный японский | Второй движок распознавания |

Порядок языков: корейский и японский — в первую очередь, китайский — позже.

## Установка

1. Скачайте `MangaLocal-Setup-x.y.z-x64.exe` со страницы сборок (Actions → build → Artifacts) и запустите. Права администратора не нужны.
2. Оставьте галочку «Установить модули распознавания текста Windows» — корейский, японский, китайский и английский.
3. При первом запуске программа один раз скачает модель (~1,1 ГБ).

### Где лежат данные

`%LOCALAPPDATA%\MangaLocal`: `config.toml`, `models\`, `cache.tsv`, `corrections.tsv`, `glossary\user.tsv`, `logs\`.
Портативный режим: если рядом с exe лежит `portable.txt`, всё хранится в папке `data` рядом с программой.

Manga Local и Wuxia Local можно ставить рядом: у них разные папки программы и данных.

## Устройство

```
wuxia-core    ядро из репозитория Wuxia Local (git-зависимость в Cargo.toml):
              очистка текста, глоссарий, промпты, кэш, группировка строк, рисование надписей
crates/app    manga-local.exe (Windows): захват экрана, Windows OCR, llama-server, оверлей, трей, панель
crates/bench  проверка качества перевода на наборе строк (.github/workflows/quality.yml)
```

## Сборка (для разработчиков)

```
cargo build -p manga-local --release  # Windows 10/11 x64, MSVC
```

Чтобы править ядро вместе с приложением, положите рядом клон wuxia-local и раскомментируйте `[patch]` в `Cargo.toml`.

Установщик и portable-архив собирает GitHub Actions (`.github/workflows/release.yml`) на каждый push в main. Хранятся 5 последних сборок. Тег `v*` публикует релиз.
