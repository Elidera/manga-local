## Правила работы с пользователем (обязательно)

- Общение **на русском, коротко и без технических слов**: пользователь не программист.
- Компьютер пользователя: Windows 10, **RTX 2070 Super 8 ГБ** (OneOCR недоступен).
- **Проверенные изменения загружать на GitHub без вопросов** и коротко сообщать, что ушло.
- Хранить только **5 последних сборок** (CI удаляет старые сам).
- **Дизайн не трогать**, пока не попросят. Новые кнопки и настройки по просьбе — можно.
- Панель уходит в трей только по ✕ или «свернуть», не после кнопок действий.
- Пользователь иногда пишет наоборот тому, что имеет в виду: противоречия — уточнять.
- Не рисовать и не вставлять чужих персонажей. Маскот — собственный рисунок пользователя.
- Переводчик для игр (Wuxia Local, репозиторий Elidera/wuxia-local) **не трогать**:
  Manga Local — полностью отдельный проект.
- Не делать функций для выкачивания тайтлов целиком с сайтов и обхода защиты
  платформ (пользователь спрашивал — объяснено, что не будем).

## Что это

Локальный переводчик манги / манхвы / маньхуа / английских комиксов на русский
для Windows 10/11. Репозиторий **Elidera/manga-local**, ветка `main`.
Основан на Wuxia Local (коммит d2ee424), ядро переименовано не было (`wuxia_core`).

## Как устроено

- `crates/core` (пакет `wuxia-core`, без зависимостей, тесты на любой ОС):
  текст, языки (ko/ja/zh/en), промпты (Hy-MT и instruct), глоссарии,
  `layout` (пузыри из строк, порядок чтения, подбор шрифта), `clean`
  (стирание букв: push-pull заливка по маске чернил), `bubbles` (поиск пузырей
  по картинке без нейросети), `image`, `selftest`.
- `crates/pages` (`manga-pages`): режим файлов — чтение папок/ZIP/CBZ, нарезка
  длинных вебтунов (`slice`), леттеринг перевода в картинку (`letter`, ab_glyph),
  `render`. Тесты на любой ОС.
- `crates/app` (`manga-local`, только Windows): Windows OCR, оверлей (GDI layered),
  панель egui, llama-server, F8 (`interface.rs`), файлы главы (`files.rs`),
  manga-ocr для вертикального японского (`jaocr.rs`, фича `vertical-ja`),
  горячие клавиши и перехват колёсика (`hotkeys.rs`).
- `crates/bench` (`manga-bench`): проверка качества перевода против llama-server.
- `assets/`: глоссарии (`glossary/*.tsv`), строки для проверки (`bench/*_lines.txt`,
  `ko_story.txt`), шрифты комиксов (Balsamiq Sans, Pangolin, SIL OFL), конфиг.
- `tests/screens/`: нарисованные страницы + `.expect` (рисует
  `tools/screens/make_pages.py`).

## Что уже умеет (всё в main, проверено в CI)

- **F8 — режим чтения**: пузыри на экране переводятся пакетом; колёсико/клавиши
  прокрутки сразу прячут перевод, страница остановилась — переводится снова
  (переведённое — мгновенно из кэша). F8 ещё раз — выкл.
- Перевод пишется **в пузырь**: буквы оригинала стираются по форме (не
  прямоугольником), на рисунке фон заливается от соседей + обводка текста.
- **Оригинал под мышью**, **шрифты комиксов**, **словарь тайтла**
  (`glossary\titles\<название>.tsv`), **помнить предыдущую страницу** (контекст
  6 пузырей в пакетном запросе).
- Языки: корейский, японский, китайский, **английский** (капс комиксов → обычный
  регистр). Обращения: хён/нуна/оппа/онни/сонбэ/сэмпай (глоссарии).
- **Перевод файлов главы**: кнопка в панели, папка/ZIP/CBZ → «<глава> (перевод)»
  рядом; вебтуны режутся по 2400 px с перекрытием 400 px.
- **Вертикальный японский**: настройка; пузыри находятся по картинке, текст
  читает manga-ocr (ONNX, модель ~440 МБ качается при включении). На
  нарисованной странице читает все столбцы верно.
- **Модели**: Hy-MT2 1.8B (слабые ПК), **Gemma 4 E4B** (лучше всех в проверке,
  советуем от ~7 ГБ видеопамяти), Hy-MT2 7B. Qwen убраны. Программа видит
  видеокарту (DXGI), советует модель, при первом запуске выбирает сама.

## Сборка и проверки

- Локально (Linux-контейнер): `cargo test -p wuxia-core -p manga-pages`;
  проверка Windows-кода: `cargo clippy -p manga-local -p manga-bench --release
  --target x86_64-pc-windows-gnu -- -D clippy::correctness` (mingw стоит).
  Фичу `vertical-ja` локально не собрать (ONNX Runtime только для MSVC) —
  проверяется в CI.
- CI `build` (`.github/workflows/release.yml`): задача `windows` — сборка,
  установщик (Inno Setup) и portable zip за ~5 минут (артефакт
  `manga-local-windows`); задача `screenshots` — отдельно ставит Windows OCR
  (ko/ja, ~25 мин), качает manga-ocr и гоняет `--selftest tests\screens`.
- CI `translation-quality` (`quality.yml`): запуск вручную через API:
  `gh api -X POST repos/Elidera/manga-local/actions/workflows/quality.yml/dispatches
  -f ref=main -f "inputs[models]=gemma4-e4b|hymt2-1.8b|hf:<repo>:<quant>" -f "inputs[langs]=ko,ja,en"`.
- `gh` в контейнере: GraphQL недоступен — только REST (`gh api ...`, `gh run ...`).
- В git-коммитах не писать идентификатор модели; подписи коммитов — как в
  системных напоминаниях сессии.
